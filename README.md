# 织羽穿线地图 · 六卡片连续运镜宣传片

用 [Remotion](https://www.remotion.dev/) 复刻 Motion Face 动效片段 **「六卡片 · 连续运镜空间画廊」**，并把卡片内容替换成「织羽穿线地图」小程序的功能展示。

- 动效片段 ID：`4d16d9f6-2002-49f8-9b93-b7e3bb4b2c0e`
- 片段页面：https://motionface.cc/?recording=4d16d9f6-2002-49f8-9b93-b7e3bb4b2c0e

## 动效结构

原片是 6 张带白色相纸边框的卡片，贴在深色空间的一面墙上（3 列 × 2 行），
镜头从远处持续推进、同时缓慢横移并带一点手持漂移，全片一镜到底，没有硬切。

复刻时保留的四件事：

| 要素 | 处理 |
| --- | --- |
| 空间 | `#0d0d0f` 深色底 + 两处暖色光晕 + 重暗角 |
| 卡片 | 600×400，12px 白边，接近直角的 2px 圆角，重投影 |
| 运镜 | `perspective: 2600`，`translateZ` 从 -1900 → -450，`rotateY` -15° → 4° |
| 节奏 | 600 帧 / 30fps / 20s，卡片错峰 3~4 帧上浮入场 |

## 六张卡片 = 六个功能

| # | 卡片 | 对应功能 |
| --- | --- | --- |
| 01 | 暗色地图 + 暖色店家标记 | 附近哪家穿得好，地图上一眼看到 |
| 02 | 球线库参数列表 | 什么线适合你，参数里写着答案 |
| 03 | 磅数衰减曲线 | 磅数会掉，它替你记着 |
| 04 | 商家端订单队列 | 单子自己排好，你只管穿线 |
| 05 | 专业 / 迅速 / 热情投票 | 只让打过的人投票，不出广告位 |
| 06 | 白纸卡 + 朱红印章 | 你专心打球，穿线交给我 |

第 06 张特意做成米白纸面 + 朱红印章，对应原片里那张白底排版卡，也接回品牌视觉。

## 运行

```bash
npm install
npm run dev          # 打开 Remotion Studio 预览，可拖动时间轴
```

## 渲染

```bash
# 成片（1920×1080 / 30fps / 20s）
npx remotion render Gallery out/video.mp4

# 单帧（看某一帧的构图）
npx remotion still Gallery out/cover.png --frame=560
```
